# Flutter Labs

## Lab 9 — Clima

Ứng dụng thời tiết cho phép nhập tên thành phố để xem nhiệt độ, biểu tượng và
lời khuyên phù hợp. Bản demo hiện dùng dữ liệu mẫu để chạy ổn định trên Web.

### Chạy ứng dụng

```bash
flutter pub get
flutter run -d chrome
```

Có thể thay `chrome` bằng `edge`, `android` hoặc `ios`. Kiểm tra thiết bị khả
dụng bằng `flutter devices`.

### Kiểm thử

```bash
flutter test
```
