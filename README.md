# Flutter Labs

## Lab 8 — BMI Calculator

Ứng dụng tính chỉ số BMI dựa trên giới tính, chiều cao, cân nặng và tuổi. Kết
quả hiển thị chỉ số, phân loại và lời khuyên sức khỏe.

### Chạy ứng dụng

```bash
flutter pub get
flutter run -d chrome
```

Có thể thay `chrome` bằng `edge`, `android` hoặc `ios`. Kiểm tra thiết bị khả
dụng bằng `flutter devices`.

### Kiểm thử

```bash
flutter test
```
