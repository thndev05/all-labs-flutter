# Flutter Labs

## Lab 3 — Dicee

Ứng dụng mô phỏng hai xúc xắc. Nhấn vào một xúc xắc hoặc nút **Lắc xúc xắc**
để tạo kết quả ngẫu nhiên và hiển thị tổng điểm.

### Chạy ứng dụng

```bash
flutter pub get
flutter run -d chrome
```

Có thể thay `chrome` bằng `edge`, `android` hoặc `ios`. Kiểm tra thiết bị khả
dụng bằng `flutter devices`.

### Kiểm thử

```bash
flutter test
```
