# Flutter Labs

## Lab 7 — Destini

Ứng dụng truyện tương tác. Mỗi lựa chọn dẫn đến một nhánh truyện và kết thúc
khác nhau; nhấn **CHƠI LẠI** để quay về đầu câu chuyện.

### Chạy ứng dụng

```bash
flutter pub get
flutter run -d chrome
```

Có thể thay `chrome` bằng `edge`, `android` hoặc `ios`. Kiểm tra thiết bị khả
dụng bằng `flutter devices`.

### Kiểm thử

```bash
flutter test
```
