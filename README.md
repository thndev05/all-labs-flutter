# Flutter Labs

## Lab 4 — Magic 8 Ball

Ứng dụng trả lời câu hỏi ngẫu nhiên bằng quả bóng Magic 8 Ball. Nhấn vào quả
bóng hoặc nút **HỎI MAGIC 8 BALL** để nhận câu trả lời mới.

### Chạy ứng dụng

```bash
flutter pub get
flutter run -d chrome
```

Có thể thay `chrome` bằng `edge`, `android` hoặc `ios`. Kiểm tra thiết bị khả
dụng bằng `flutter devices`.

### Kiểm thử

```bash
flutter test
```
