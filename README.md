# Flutter Labs

## Lab 6 — Quizzler

Ứng dụng trắc nghiệm Đúng/Sai. Chọn câu trả lời, xem biểu tượng kết quả và
nhận điểm sau khi hoàn thành toàn bộ câu hỏi.

### Chạy ứng dụng

```bash
flutter pub get
flutter run -d chrome
```

Có thể thay `chrome` bằng `edge`, `android` hoặc `ios`. Kiểm tra thiết bị khả
dụng bằng `flutter devices`.

### Kiểm thử

```bash
flutter test
```
