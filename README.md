### Chạy ứng dụng

```bash
flutter pub get

# Chrome
flutter run -d chrome
```

Các nền tảng khác:

```bash
# Microsoft Edge
flutter run -d edge

# Android emulator hoặc thiết bị Android
flutter run -d android

# Windows desktop
flutter run -d windows

# iOS simulator (cần macOS và Xcode)
flutter run -d ios
```

Kiểm tra các thiết bị khả dụng bằng `flutter devices`. Nhấn `r` để hot reload
và `q` để dừng ứng dụng.
