# Flutter Labs

## Lab 5 — Xylophone

Ứng dụng đàn Xylophone gồm 7 phím màu. Chạm vào từng phím để phát nốt nhạc.

### Chạy ứng dụng

```bash
flutter pub get
flutter run -d chrome
```

Có thể thay `chrome` bằng `edge`, `android` hoặc `ios`. Kiểm tra thiết bị khả
dụng bằng `flutter devices`.

### Kiểm thử

```bash
flutter test
```
